> [!DICA]
> Tudo aqui segue o **Novo Acordo Ortográfico**, obrigatório no Brasil desde **1º/01/2016**.[^1][^2] A banca adora palavras que **perderam** o acento ou o hífen.

## Alfabeto e trema

- O alfabeto tem **26 letras**: o Acordo incluiu oficialmente **K, W e Y**.[^1]
- O **trema foi abolido**: linguiça, frequente, tranquilo, cinquenta. Só fica em nomes estrangeiros e derivados (Müller, mülleriano).[^1]

> [!SIMPLES]
> K, W e Y já eram usados em nomes como "Kátia" e "show"; o Acordo só oficializou. E os dois pontinhos do "ü" sumiram das palavras portuguesas.

## Uso do hífen com prefixos

| Regra | Exemplos |
|---|---|
| Prefixo termina em **vogal** + palavra começa com **vogal diferente** → **junta** | autoescola, infraestrutura, extraoficial, semiaberto |
| Prefixo termina em vogal + palavra começa com a **mesma vogal** → **hífen** | micro-ondas, anti-inflamatório, contra-ataque |
| Prefixo termina em vogal + palavra começa com **r ou s** → **junta e dobra** | antirrugas, ultrassom, contrassenso, minissaia |
| Palavra começa com **h** → **hífen** | anti-higiênico, super-homem, pré-história |
| Prefixo termina em **consoante** + **mesma consoante** → **hífen** | inter-racial, super-resistente, sub-base |
| **Sub** + palavra com **r** → **hífen** | sub-região, sub-reitor |
| **Ex, vice, sem, além, aquém, recém, pós, pré, pró** (tônicos) → **hífen** | ex-diretor, vice-presidente, recém-nascido, pós-graduação, pré-vestibular |
| **Co** → junta sempre | coautor, cooperar, coerdeiro |
| **Mal** + vogal, **h** ou **l** → hífen | mal-educado, mal-humorado; mas **malcriado** |

Fonte: Acordo Ortográfico, Base XVI.[^1]

> [!SIMPLES]
> A ideia geral do Acordo: **letras iguais se separam com hífen** (micro-ondas, inter-racial) e **letras diferentes se juntam** (autoescola). Se juntar e cair **r** ou **s** entre vogais, dobra a letra para não mudar o som (anti + rugas = **antirrugas**).

### Compostos com elemento de ligação

Palavras como **dia a dia**, **fim de semana**, **pé de moleque**, **mão de obra** **perderam o hífen**. Exceções: nomes de **plantas e animais** (bem-te-vi, erva-doce, joão-de-barro) e algumas consagradas (**cor-de-rosa**, **água-de-colônia**, **mais-que-perfeito**, **pé-de-meia**).[^1]

> [!PEGADINHA]
> "Dia-a-dia" com hífen é forma **antiga**. Hoje é **dia a dia**.

## Uso de letras: as dúvidas clássicas

| Regra | Exemplos |
|---|---|
| **-ês, -esa** (origem, título) | português, francesa, princesa, marquês |
| **-ez, -eza** (substantivo vindo de adjetivo) | rigidez (rígido), beleza (belo), pobreza |
| **-isar** se a palavra base tem **s**; senão **-izar** | analisar (análise), pesquisar; **realizar** (real), civilizar |
| **X** depois de **ditongo** | caixa, peixe, ameixa, frouxo |
| **X** depois de **en-** inicial | enxada, enxugar, enxergar; exceção: **encher**, **encharcar** (de cheio, charco) |
| **X** depois de **me-** inicial | mexer, mexerica; exceção: **mecha** |
| **Ç / SS** em substantivos: ceder → **cessão**; agredir → **agressão**; permitir → **permissão**; deter → **detenção**; pretender → **pretensão** | |
| **Viajem** (verbo) x **viagem** (substantivo) | "Espero que eles **viajem**." / "A **viagem** foi boa." |
| **Mal** (oposto de bem) x **mau** (oposto de bom) | "Ele agiu **mal**." / "Ele é um **mau** aluno." |

Fonte: Bechara.[^3]

> [!SIMPLES]
> Não tente decorar tudo: guarde os **padrões** (ditongo → x; nacionalidade → ês; adjetivo virando substantivo → ez/eza) e faça o **teste do oposto** para mal/mau (troque por bem/bom).

## Acentuação gráfica

### Regras pela sílaba tônica

| Tipo de palavra | Leva acento se terminar em | Exemplos |
|---|---|---|
| **Oxítona** (última sílaba forte) | **a(s), e(s), o(s), em, ens** | sofá, café, cipó, também, parabéns |
| **Paroxítona** (penúltima forte) | **l, n, r, x, ps, ã(s), ão(s), i(s), us, um, uns, ditongo** | fácil, hífen, caráter, tórax, bíceps, órfã, órgão, júri, vírus, álbum, história |
| **Proparoxítona** (antepenúltima forte) | **todas** | lâmpada, médico, público |
| **Monossílabo tônico** | **a(s), e(s), o(s)** | pá, pé, pó, mês, nós |

Fonte: Acordo Ortográfico, Bases VIII a XI.[^1]

> [!SIMPLES]
> As paroxítonas são a maioria das palavras do português. Por isso **elas quase nunca têm acento** (casa, livro, item). Só ganham acento quando terminam de um jeito "diferente" (l, n, r, x, ps, ã…).

> [!PEGADINHA]
> **Hífen** tem acento, mas **hifens** não. **Pólen**, mas **polens**. **Item** e **itens** não têm acento (paroxítonas terminadas em -em/-ens).

### O que mudou com o Acordo

| Regra | Antes | Agora |
|---|---|---|
| Ditongos abertos **éi, ói** em **paroxítonas** perdem o acento | idéia, assembléia, heróico, jibóia | **ideia, assembleia, heroico, jiboia** |
| Mas em **oxítonas e monossílabos** o acento fica | | papéis, herói, céu, dói |
| **I e U** tônicos depois de **ditongo** em paroxítonas perdem o acento | feiúra, baiúca | **feiura, baiuca** |
| Hiatos **ee** e **oo** perdem o acento | crêem, dêem, vôo, enjôo | **creem, deem, voo, enjoo** |
| Acento diferencial **cai** | pára, pêlo, pólo, pêra | **para, pelo, polo, pera** |

Fonte: Acordo Ortográfico, Bases VIII a XI.[^1]

> [!CAI]
> **Assembleia** não tem mais acento. Atenção: o próprio nome da **ALEPA** aparece nas provas assim.

### Acentos que continuam

- **Hiato com i/u tônico** sozinho na sílaba: sa-**í**-da, sa-**ú**-de, ba-**ú**, pa-**í**s. Não leva acento se vier seguido de **nh** (ra-i-nha) ou formar sílaba com outra letra (ru-im, Ra-ul).[^1]
- **Pôde** (passado) x pode (presente).[^1]
- **Pôr** (verbo) x por (preposição).[^1]
- **Têm, vêm** (plural) x tem, vem (singular). Derivados: ele **contém**, eles **contêm**; ele **detém**, eles **detêm**.[^1]
- **Fôrma** (molde) é **facultativo**.[^1]

> [!SIMPLES]
> Os acentos que sobreviveram servem para **diferenciar palavras de verdade**: "ele **pôde** ontem" x "ele **pode** hoje"; "vou **pôr** a mesa" x "passei **por** aqui".

## Revisão rápida {- .colunas}

- Alfabeto: 26 letras (K, W, Y).
- Trema abolido (linguiça), exceto nomes estrangeiros.
- Vogal + vogal diferente: junta (autoescola).
- Letras iguais: hífen (micro-ondas, inter-racial).
- Vogal + r/s: dobra (antirrugas, ultrassom).
- Antes de h: hífen (anti-higiênico).
- Ex, vice, pós, pré, recém: hífen.
- Dia a dia, fim de semana: sem hífen.
- Oxítonas: a, e, o, em, ens.
- Proparoxítonas: todas acentuadas.
- Ideia, assembleia, heroico: sem acento.
- Papéis, herói, céu: com acento.
- Creem, deem, voo, enjoo: sem acento.
- Para, pelo, polo: sem acento diferencial.
- Pôde, pôr, têm, vêm: continuam.

## Flashcards {- .flashcards}

- Quais letras o Acordo incluiu no alfabeto? :: **K, W e Y** (26 letras).
- O trema ainda existe? :: **Não**, exceto em nomes estrangeiros (Müller).
- auto + escola :: **autoescola** (vogais diferentes: junta).
- micro + ondas :: **micro-ondas** (vogais iguais: hífen).
- anti + rugas :: **antirrugas** (vogal + r: junta e dobra).
- anti + higiênico :: **anti-higiênico** (antes de h: hífen).
- dia a dia leva hífen? :: **Não**.
- Quais oxítonas são acentuadas? :: Terminadas em **a(s), e(s), o(s), em, ens**.
- Hífen x hifens: qual tem acento? :: Só **hífen**.
- Ideia ou idéia? :: **Ideia** (ditongo aberto em paroxítona perdeu o acento).
- Herói perdeu o acento? :: **Não**: é oxítona, o acento fica.
- Vôo ou voo? :: **Voo**.
- Pára (verbo) ainda tem acento? :: **Não**: **para**.
- Pôde x pode :: **Pôde** = passado; **pode** = presente.
- Eles têm / ele tem :: **Têm** (plural) com acento; **tem** (singular) sem.

## Questões de fixação {-}

::: questao
Está grafada corretamente, de acordo com o Novo Acordo Ortográfico, a palavra:
A) auto-escola
B) micro-ondas
C) anti-rugas
D) contra-senso
E) infra-estrutura
= B | Vogais iguais pedem hífen. As demais: autoescola, antirrugas, contrassenso, infraestrutura.
:::

::: questao
Todas as palavras estão corretamente acentuadas em:
A) idéia, herói, papéis
B) ideia, heroico, papéis
C) ideia, heróico, papeis
D) idéia, heroico, papeis
E) ideia, herói, papeis
= B | Paroxítonas com éi/ói perdem o acento (ideia, heroico); oxítonas mantêm (papéis, herói).
:::

::: questao
Segundo o Novo Acordo Ortográfico, a palavra que perdeu o acento é:
A) pôde
B) têm
C) vôo
D) pôr
E) café
= C | Hiatos ee/oo perderam o acento: voo, enjoo, creem.
:::

::: questao
O nome do órgão legislativo estadual está corretamente grafado em:
A) Assembléia Legislativa
B) Assembleia Legislativa
C) Assembléa Legislativa
D) Assemblêia Legislativa
E) Asembleia Legislativa
= B | Assembleia: ditongo aberto "ei" em paroxítona não é mais acentuado.
:::

::: questao
Assinale a alternativa em que a palavra NÃO deve receber acento gráfico:
A) carater
B) torax
C) itens
D) orfã
E) juri
= C | Paroxítonas terminadas em -ens não são acentuadas. Caráter, tórax, órfã e júri levam acento.
:::

::: questao
Está correta a grafia em:
A) Espero que eles façam uma boa viagem.
B) Espero que eles viagem amanhã.
C) A viajem foi cansativa.
D) Ele é um mal funcionário.
E) Ele se comportou mau.
= A | Viagem é substantivo; viajem é verbo. Mau é oposto de bom; mal é oposto de bem.
:::

::: questao
Qual palavra está escrita corretamente?
A) enxer
B) analizar
C) mexer
D) belesa
E) princeza
= C | X após "me-" inicial. Corretas: encher, analisar, beleza, princesa.
:::

::: questao
Está corretamente grafada a expressão:
A) dia-a-dia
B) fim-de-semana
C) pé-de-moleque
D) cor-de-rosa
E) mão-de-obra
= D | Compostos com elemento de ligação perderam o hífen, mas cor-de-rosa é exceção consagrada.
:::

::: questao
Em "Ontem ele não ___ vir, mas hoje ele ___", completam corretamente as lacunas:
A) pode / pode
B) pôde / pode
C) pode / pôde
D) pôde / pôde
E) póde / pode
= B | Pôde (passado) mantém o acento diferencial; pode (presente) não tem.
:::

::: questao
Estão corretas as palavras, quanto ao hífen:
A) ex-diretor, vice-presidente, coautor
B) exdiretor, vice-presidente, co-autor
C) ex-diretor, vicepresidente, coautor
D) ex diretor, vice-presidente, co-autor
E) exdiretor, vicepresidente, coautor
= A | Ex e vice pedem hífen; o prefixo co se junta sempre.
:::
